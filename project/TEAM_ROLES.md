# Suggested Team Roles

Recommended team size: **3–5 members**.

Roles are project responsibilities, not permanent Mettelo identities.

## Data Pipeline Engineer
Owns:
- ingestion;
- file acquisition/loading;
- metadata capture;
- rerun behaviour;
- logging/error handling.

## Data Modelling Engineer
Owns:
- entity relationships;
- staging/core/curated models;
- transformation logic;
- SQL/dbt model organisation.

## Data Quality Engineer
Owns:
- profiling;
- tests;
- reconciliation;
- referential integrity;
- quality reporting.

## Analytics / Data Product Engineer
Owns:
- analytics-ready marts;
- validation queries;
- representative analytical outputs;
- usability of curated data.

## Technical Lead / Project Coordinator
May be combined with another role.

Owns:
- architecture coherence;
- delivery planning;
- PR/review discipline;
- integration;
- final QA and handover.

Every member must still contribute technically. Role titles should not be used to isolate one person from the engineering work.
