# 03 — Pipeline & Data Quality

Document:
- ingestion process;
- orchestration/run order;
- idempotency/rerun behaviour;
- metadata capture;
- validation rules;
- quality tests;
- failed-test handling;
- reconciliation;
- logging;
- error handling;
- pipeline dependencies.

Include evidence of test execution.

Minimum quality domains:
- uniqueness;
- completeness;
- validity;
- consistency;
- referential integrity;
- volume reconciliation.
