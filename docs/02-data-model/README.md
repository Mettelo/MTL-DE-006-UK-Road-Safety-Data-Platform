# 02 — Data Model

Document the target architecture and modelling decisions.

Required:
- architecture diagram;
- ERD;
- raw/staging/core/curated layers;
- model names;
- grain of every core model;
- primary/relationship keys;
- source-to-target mapping;
- coded-field decoding approach;
- date/time handling;
- naming conventions;
- slowly changing/reference-data approach where relevant.

A reviewer should understand the model without reading the pipeline code.
