# 04 — Analysis & Output Validation

Use the curated layer to prove that the data product is analytically useful.

Provide a concise set of validation outputs covering several of:
- trends over time;
- casualty severity;
- road users;
- vehicle groups;
- geography;
- road/environment conditions.

For each output document:
- metric definition;
- table/model used;
- filters;
- result;
- interpretation;
- limitations.

This is not primarily a dashboard project. Keep visualisation proportional to the engineering objective.
