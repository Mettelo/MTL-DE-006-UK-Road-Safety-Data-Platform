# 01 — Discovery

Document the source before engineering it.

Cover:
- business purpose;
- users;
- source ownership;
- source URLs;
- period used;
- licensing/access;
- grain of collisions, vehicles and casualties;
- keys and relationships;
- important coded variables;
- schema changes across the selected years;
- missing-value conventions;
- data-quality risks;
- source limitations;
- assumptions.

Include a short data profile for each source file.

Do not start by building charts. Establish what the data means first.
